claude-task

Four reasons to hand it the backlog四个理由，放心把任务池交给它

Async task pipeline for Claude Code: backlog in, reviewed & test-verified commits out, live progress pane.异步任务流水线：需求进任务池，后台 agent 逐个交付、机器验收，面板实时看进度。

01

From assistant to team从助理到团队

Your main session only listens, dispatches and accepts. Implementation goes to a background worker with a fresh context; review goes to code-reviewer / security-analyst. You talk to a project lead, not to an assistant too busy coding to listen.主会话只做三件事：听你说、派活、验收。具体实现交给全新上下文的后台 worker，代码审查交给 code-reviewer / security-analyst。你面对的是一个项目经理，而不是一个埋头敲代码、顾不上理你的助理。

02

Every request is a ticket, delivered to engineering standards需求即任务，按工程标准交付

A casual request becomes a ticket (ID, priority, acceptance criteria), then implementation, a review gate, and the dispatcher re-running the tests itself. Archived only after you confirm. Every step lives in plain Markdown in your repo: traceable and diffable.一句口语需求 → 规范任务（ID、优先级、验收标准）→ 实施 → 审查门禁 → 调度员亲自重跑测试 → 「待验证」→ 你确认后归档。每一步都落在仓库里的 Markdown 文件中，可追溯、可 diff。

03

Fully async: fire and forget全异步：想到就丢

No more waiting for one thing to finish before asking for the next. Speak up any time, or qtask "…" from any terminal; the current task is never interrupted. Anything that needs your call goes to a decision queue; everything else keeps moving with the most conservative choice.不用再和 agent 同频，不用等它做完一件才提下一件。随时在会话里插话，或在任意终端 qtask "描述" 投递；当前任务不受打扰。需要你拍板的挂进「待决策」，其余按最保守的做法继续推进。

04

Everything visible at a glance进度一目了然

A side pane and a status line show what's running, what's done, what's left and what's waiting on you; toasts fire when a task needs verification or a decision. Completion rate, first-pass rate and median cycle time included.右侧面板 + 输入框下方状态行实时显示：正在做什么、做完了什么、还剩什么、等你决定什么；任务进入待验证 / 待决策 / 阻塞时弹提醒。完成率、一次通过率、中位周期一并给出。

How it works工作原理

One task at a time, checked by a machine一次一个任务，机器验收

Workers run one at a time, in order. Each gets a fresh context, and no task is called delivered on a worker's word alone.worker 串行执行，一次一个，各自全新上下文；没有任何任务只凭 worker 自述就算交付。

  1. Request需求in plain words口语即可
  2. Ticket任务ID, priority, acceptance criteriaID、优先级、验收标准
  3. Workerworkerfresh context, commits全新上下文，提交
  4. Review gate审查门禁code review + security代码审查 + 安全
  5. Dispatcher re-runs tests调度员重跑测试not the worker's word不信 worker 自述
  6. Awaiting verification待验证the final call is yours最终确认在你
  7. You confirm你确认or send it back或打回重做
  8. Archived归档Markdown in your repo仓库里的 Markdown

Async inputs, any time异步输入，随时可投

  • Talk to the main session while the loop runs. New requests are queued; the current task is not interrupted.循环运行时直接在会话里说，新需求排进队列，当前任务不受打扰。
  • qtask "describe it" from any terminal (optional, installed separately), to drop in tasks or answer decisions.在任意终端 qtask "描述" 投递任务或答复决策（可选，需单独安装）。
Guardrails护栏

Why you can walk away为什么敢放手

The loop is built so that a bad run is caught, rolled back and explained, not silently merged.循环的设计目标：出错的一轮会被发现、回滚并留下说明，而不是悄悄合入。

  • Never trusts the worker's word不信 worker 自述The dispatcher re-runs the tests itself.调度员亲自重跑测试才算完成。
  • Catches cheating防作弊Detects weakened tests: deleted cases, new skips, fewer assertions.自动检测测试被改弱：删用例、加 skip、断言变少。
  • Stops and asks on high-risk choices高风险处停下来问你Schema/migrations, auth/crypto, billing, data deletion, public APIs, deployment, dependencies.schema/迁移、认证/加密、计费、删数据、对外 API、部署、依赖，有多种做法时停下来问你。
  • Failures roll back, with evidence kept失败自动回滚，证据保留Failed attempts are rolled back and kept under refs/auto-failed/* for review; two failures → blocked.失败自动回滚，并保留 refs/auto-failed/* 供你复盘；失败两次转阻塞。
  • Never on main, never pushes不碰主分支，从不 pushNever runs on main/master, never pushes; stops on a STOP file, task/time budgets, or three rounds without progress.不在 main/master 上跑，从不 push；STOP 文件、任务数 / 时长预算、连续无进展三重停机。
Quick start快速开始

Three steps to your first loop三步跑起第一个循环

Run these inside a Claude Code session.以下命令在 Claude Code 会话里执行。

  1. 1

    Install, then open a new session安装，然后新开一个会话

    /plugin install task --marketplace qiqll/claude-task
  2. 2

    In the new session, set up the backlog in your project, then add a task在新会话里为项目建任务池，再录入任务

    /task:init
/task:add add CSV export to the reports page
  3. 3

    Start the loop and go do something else启动循环，去忙别的

    /task:loop

/task:loop needs a git repository and a non-main branch. The docked side pane needs Claude Code's full-screen layout (CLAUDE_CODE_NO_FLICKER=1) and a terminal at least 110 columns wide; otherwise /task-dash prints a text snapshot instead. /task:loop 需要 git 仓库，并且要在非 main 分支上运行。右侧停靠面板需要全屏布局（CLAUDE_CODE_NO_FLICKER=1）且终端不少于 110 列，否则 /task-dash 会输出文字快照。
