How it works

Every request becomes a ticket

  1. Requestplain language
  2. TicketID · priority · acceptance
  3. Workerfresh context
  4. Review gatecode + security
  5. Dispatcher re-runs testsnot the worker's word
  6. To verifyyou confirm → archived

Add tasks any time — in the chat, or qtask "…" from any terminal. The running task is never interrupted.

claude-taskqiqll.github.io/claude-task
Why you can walk away

Five guardrails

  • ✓
    Doesn't trust the workerThe dispatcher re-runs your tests itself.
  • ✓
    Catches weakened testsDeleted cases, new skips, fewer assertions.
  • ✓
    Asks before risky changesSchema, auth, billing, deletes, public APIs, deploy, deps.
  • ✓
    Rolls back failuresKept under refs/auto-failed/* for review.
  • ✓
    Never on main, never pushesStops on STOP file, budgets, or no progress.
