```markdown
### T-NNN 任务标题
**完成：** YYYY-MM-DD · **优先级：** PN · **模块：** XXX
**结论：** 一句话说清做了什么、现在能用了吗。

**遗留：** 无 / 或列出转为新任务的 ID
```
